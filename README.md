# 🎓 Wanng LMS - Hệ Thống Ôn Thi Trắc Nghiệm Sinh Viên (DNTU)

Website luyện thi trắc nghiệm tinh gọn, trực quan theo phong cách Terminal / Minimalist dành cho sinh viên trường Đại học Công nghệ Đồng Nai (DNTU).

---

## 📚 Danh Mục Môn Học Hiện Có

1. **Pháp Luật Đại Cương (PLĐC):**
   - 189 câu hỏi trắc nghiệm chuẩn qua 6 chương.
   - Đường dẫn: `/pldc`

2. **Kinh Tế Chính Trị Mác - Lênin (KTCT):**
   - 304 câu hỏi trắc nghiệm qua 6 chương.
   - Đường dẫn: `/ktct`

---

## ⚡ 5 Chế Độ Luyện Tập Chuyên Sâu

- **Ôn tập (Hiện đáp án):** Click chọn đáp án trắc nghiệm, nhận diện đúng/sai và xem đáp án chuẩn ngay lập tức.
- **Thi thử (Tính giờ):** Đếm ngược thời gian, ẩn đáp án, nộp bài tính điểm thang 10 kèm phân loại.
- **Gõ đáp án (Ôn tập):** Hiển thị 4 lựa chọn, người học gõ lại toàn bộ nội dung văn bản của đáp án vào ô lệnh `wanng>` để tăng cường khả năng ghi nhớ câu từ.
- **Gõ đáp án (Tính giờ):** Luyện gõ toàn bộ đáp án dưới áp lực đồng hồ đếm ngược.
- **Flashcard:** Lật thẻ 2 mặt ghi nhớ nhanh trước giờ thi (hỗ trợ phím Space, phím mũi tên).

---

## 🛠️ Tính Năng Hỗ Trợ

- **Tự động lưu câu sai:** Tự động ghi nhận câu trả lời sai vào kho *"Câu cần ôn lại"* để luyện riêng.
- **Streak học tập:** Theo dõi chuỗi ngày ôn luyện liên tục.
- **Lịch sử làm bài:** Bảng lưu trữ kết quả và điểm số các lần luyện thi gần nhất.
- **Tùy chỉnh cỡ chữ:** Phóng to toàn trang (100% / 125% / 150%) tối ưu cho màn hình Full HD, 2K và di động.

---

## 💻 Cài Đặt & Khởi Chạy

```bash
# Cài đặt thư viện
npm install

# Chạy môi trường phát triển (Dev Server)
npm run dev

# Đóng gói sản phẩm (Production Build)
npm run build
```
